# Changelog

## [0.1.0] - 2026-10-15

### Added
- Gameplay Tags with Tag Manager and drawers.
- Attributes with dynamic maximum and Add / Multiply / Override modifiers.
- Gameplay Effects: instant, duration, infinite, periodic, executions, stacking, immunity, cleanse,
  ongoing requirements.
- Gameplay Abilities with cost, cooldown, tags, event triggers and waits.
- Gameplay Events and the Animation Event relay.
- Gameplay Cues with prefab and audio cues, pooled.
- Attribute Reactions.
- Ability Debugger window.
- Optional Input System binder.
- Basic Combat sample.
- Automated EditMode tests.
- Full documentation set in `Documentation~`.
